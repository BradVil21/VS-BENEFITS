Blocked IPs

Anyone on this list gets a 404 “you have been blocked” page instead of the website. This portal and the client area are never blocked, so you cannot lock yourself out of the screen you would need to undo it.

Block an address

Paste an IP, or use the Block button on a lead card — that one fills the address in for you.

Currently blocked

On IPv6. A home IPv6 address rotates its second half every few hours, so an exact match would stop working almost immediately. IPv6 entries are therefore stored and matched as the /64 prefix — the stable half the internet provider assigns to the household. IPv4 addresses are matched exactly.
How fast. A block takes effect within about a minute; unblocking is the same.
Checking it worked. Have the person open vshealthbenefits.com/__blockcheck. It reports the address the website sees them as and whether it is currently blocking them — a plain answer that no browser cache can fake. If it says blocked: false but they still see the 404 page, it is their own browser cache: a hard refresh clears it.
